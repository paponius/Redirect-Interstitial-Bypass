## Background

Originally created for Google's "I Feel Lucky" features and legacy redirects. In 2026, Google re-introduced intermediate interstitial redirect pages specifically for source links within AI Mode results.

---

## URI Parameter Reference by Observation Period

### Current Observations (2026)

* **`sa`**: Search action indicator; specifies the tracking context or type of action for the user's click (e.g., `sa=t`).
* **`source`**: Surface or platform origin of the interaction (e.g., `source=web`).
* **`rct`**: Internal routing or result content type parameter used for backend response formatting.
* **`url`**: The primary percent-encoded target destination URI.
* **`ved`**: Visual Element Data; an encrypted tracking token containing metadata on the exact position, layout, and context of the clicked link.
* **`opi`**: Origin parameter indicator or internal session/experiment configuration flag.
* **`iflsig`**: Google cryptographic signature authenticating trusted target redirects (e.g., Google-affiliated or pre-approved safe domains). Bypasses the need for script intervention.
* **`psig`**: Equivalent authentication signature token used specifically for Google Picture Search redirects.

### Legacy Observations (~2019)

* **`q`**: Fallback search or target URI parameter; historically held the target URI, or was present and empty when `url` was used.
* **`ust`**: Timestamp or internal tracking metric (integer).
* **`usg`**: Legacy Google redirection security signature hash (`[a-Z0-9_]`).
* **`esrc`**: External source parameter from older search result tracking structures.
* **`cd`**: Result rank/position identifier in older SERP layouts.
* **`btnI`**: "I Feel Lucky" trigger flag (`btnI=`).

## Technical Notes & Edge Cases

### The Cookie Race Condition (Delay Rationale)

* **Issue:** Occasionally, browser session cookies are not transmitted instantly with fast redirects, leading to generic target pages (e.g., signed-out states, incorrect localized languages such as IMDb issues).
* **Observation:** Primarily noted in Firefox. A short delay (e.g., 1–2 seconds) resolves cookie synchronization before executing `window.location.replace()`.

### Native Safety Interstitial Logic

* The native Google Redirection Notice guards against fraudulent or malicious external sites.
* **Bypass Conditions:** The script must avoid overriding Google when it natively permits direct navigation:
* If trusted tokens (`iflsig` or `psig`) are present, Google is already handling or permitting the direct route.
* If strict domain filtering is preferred, use `config.sites` to limit auto-redirection to an explicitly approved whitelist rather than a blanket global override.
